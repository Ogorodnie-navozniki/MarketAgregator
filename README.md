# MarketAgregator
## Что мы предлагаем?иеуиу

#### Мы предлагаем  Маркет-Агрегатор который поможет пользователю сэкономить время, которое он тратит на поиск товара, сравнение цен, чтение отзывов, делая всё это за него. Наш сайт будет с помощью ИИ анализировать запрос пользователя, а после выдавать все товары со всего интернета, с лучшими ценами, отзывами и т.д.

## Проблема

#### Пользователю когда необходимо что-то приобрести, ему нужно просмотреть множество маркетплейсов и ресурсов, сравнивать цены, читать отзывы, корректно формулировать запросы чтобы найти то что надо, проверять надёжность продавца

## Актуальность

#### Рынок онлайн-покупок растёт и развивается, а время пользователей всё сокращается. Ручной поиск и сравнение десятков товаров на десятках сайтов - неэффективная трата времени времени в условиях современного информационного шума

# MarketAgregator
## Что мы предлагаем? блаблабла

### Мы предлагаем  Маркет-Агрегатор, помогающий пользователю сэкономить время, которое он тратит на поиск товара, сравнение цен, чтение отзывов, делая всё это за него. Наш сайт будет с помощью ИИ анализировать запрос пользователя, а после выдавать все товары со всего интернета, с лучшими ценами, отзывами и т.д.

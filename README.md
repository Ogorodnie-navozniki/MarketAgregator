# Маркет-Агрегатор
## Что мы предлагаем?

#### Мы предлагаем  Маркет-Агрегатор, помогающий пользователю сэкономить время, которое он тратит на
- поиск товара
- сравнение цен
- чтение отзывов;

делая всё это за него. Наш сайт будет анализировать запрос пользователя с помощью ИИ, а после выдавать все товары из интернета с лучшими ценами, отзывами и т.д.

## Проблема

#### Когда пользователю необходимо что-то приобрести, ему нужно просмотреть множество маркетплейсов и ресурсов, сравнить цены, прочитать отзывы, корректно сформулировать запросы, чтобы найти то, что надо.

## Актуальность

#### Рынок онлайн-покупок растёт и развивается, а время пользователей всё сокращается. Ручной поиск и сравнение десятков товаров на сотнях сайтов - неэффективная трата времени в условиях современного информационного шума.

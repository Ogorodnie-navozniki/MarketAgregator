# MarketAgregator
## Что мы предлагаем?ЛОХ

### Мы предлагаем  Маркет-Агрегатор который поможет пользователю сэкономить время, которое он тратит на поиск товара, сравнение цен, чтение отзывов, делая всё это за него. Наш сайт будет с помощью ИИ анализировать запрос пользователя, а после выдавать все товары со всего интернета, с лучшими ценами, отзывами и т.д.
